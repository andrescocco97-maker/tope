# Tope

App de gastos del hogar. Una sola plata, un solo número: lo que te queda esta semana (y, entre paréntesis, el mes).

## Qué hace
- Carga en 3 toques: micrófono del teclado ("ypf veinticinco mil", "veinte dólares spotify") o botón +.
- Pesos y dólares: la cotización la fijás en Plan (o traés la del día). Cada gasto guarda el dólar al que se cargó.
- "Lo que queda del mes": libre para gastar, vitales por cubrir, ahorro por apartar y anuales. Se calcula solo, sin elegir bolsillo.
- Casa: ladrillos y porcentaje de la meta.
- Tengo: patrimonio neto (lo que tenés menos lo que debés), en pesos o dólares, con evolución mes a mes.

## Publicar en GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root. Después abrir `https://USUARIO.github.io/tope/` en Chrome del celu → menú ⋮ → "Instalar app".

## Datos
Todo queda guardado en el celular (localStorage). Nada de números personales va en el código. Respaldo: Plan → "Copiar todo".
